# 3-minute demo script (hard limit 3:00; this runs about 2:50)

Record on the live site: https://eri-hackathon.netlify.app (fictional sample figures).

## Before you press record (10 minutes)

1. Open these tabs in one browser window and visit each once so the first load is out of the way:
   1. `/` (public Trust Desk), signed out or in a private window
   2. `/witness`, signed in as `amaka@eri.vote`
   3. `/dashboard` (Proof Tree), signed in as `admin@eri.vote` or `observer@eri.vote` in a second browser profile
   4. `/phone` (Field channels, admin only)
   5. `/results` (Results trail)
2. Passwords are in `PRESENTER-NOTES.md`. Sign in on live once beforehand to confirm they work.
3. Decide the starting state:
   - **Keep the current state** (Ward 04 already red). Skip playing the Live Ear clip and just show the result.
   - **Fresh state:** Administration → ↺ Clear live activity, then play **Ward 04 collation** in Live Ear on camera. It takes about 20 seconds,
     so cut or speed it up in the edit.
4. PU 017 and 029 must still be unwitnessed. If you have already submitted them for real, use the practice button on the video.
5. Browser zoom 110%, notifications off, one microphone, a quiet room.

## If something goes wrong on camera

- A page is slow: cut to the next tab and keep talking. First loads can take 2 to 8 seconds, which is why you visit each page beforehand.
- A submit says the polling unit already has your figures: use **Try without recording** and say so.
- Do not click Clear live activity during the recording unless you intend to replay the Ward 04 clip.
